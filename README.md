# Reel Estate

אפליקציית ווב שהופכת תמונות של נכס לרילס שמראה את החלל: תנועת מצלמה ב-AI לכל חלל, אור (יום / שעת זהב / דמדומים), כותרת פתיחה, שמות חללים, כרטיס סיום ממותג ומוזיקה. הייצוא ל-MP4 קורה בדפדפן.

משתמשים נרשמים במייל, התצוגה המקדימה חינמית, ויצירת וידאו AI עולה קרדיטים שקונים במנוי חודשי או בחבילות (סליקה דרך Grow).

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # למלא את המשתנים
npm run dev
```

בלי משתני סביבה האפליקציה רצה במצב דמו: הכל עובד חוץ מיצירת וידאו AI ותשלומים.

## מה צריך להגדיר

| משתנה | מאיפה |
|---|---|
| `FAL_KEY` | fal.ai → Dashboard → Keys |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase (פרויקט studio-hq) → Project Settings → API |
| `SUPABASE_SERVICE_ROLE_KEY` | אותו מקום, המפתח הסודי. שרת בלבד. |
| `GROW_*` | מהתמיכה של Grow, אחרי שמבקשים גישת API (Light API) |

בנוסף ב-Supabase → Authentication → URL Configuration: להוסיף את `https://<הדומיין>/auth/callback` ל-Redirect URLs. לפני השקה כדאי לחבר SMTP משלך (למשל Resend), כי שליחת המיילים המובנית של Supabase מוגבלת לכמה בשעה.

## Grow: מה לבקש מהתמיכה

1. גישת API ל-Light API, עם `userId` ו-`apiKey`.
2. שני עמודי תשלום: עמוד הוראת קבע (מנויים) ועמוד חיוב רגיל (חבילות). ה-`pageCode` של כל אחד הולך ל-`GROW_PAGE_CODE_RECURRING` ו-`GROW_PAGE_CODE_ONETIME`.
3. הפעלת Webhooks לחיובים חודשיים ולחיובים שנכשלו, לכתובת `https://<הדומיין>/api/billing/webhook`. את ה-`webhookKey` שהם נותנים שמים ב-`GROW_WEBHOOK_KEY`.
4. לשאול אם להוראת קבע פתוחה צריך לשלוח `paymentNum`. אם כן, לשים אותו ב-`GROW_RECURRING_CHARGES`.

בדיקה בסביבת sandbox: `GROW_ENV=sandbox`. לייצור: `GROW_ENV=production`.

## איך התשלומים עובדים

1. `/pricing` → `/checkout` (שם ונייד, ש-Grow דורש) → השרת פותח עמוד תשלום ב-Grow ומעביר אליו.
2. Grow קורא ל-`/api/billing/notify`. השרת מאמת את ה-processId וה-processToken ששמר, מעדכן קרדיטים ושולח `approveTransaction`.
3. חיוב חודשי (מהחודש השני) מגיע ל-`/api/billing/webhook` ומחדש את קרדיטי המסלול. חיוב שנכשל מעביר את המנוי ל-past_due.
4. ביטול מעמוד החשבון שולח ל-Grow `updateDirectDebit` עם `changeStatus=2`. הקרדיטים נשארים עד סוף התקופה.

מודלים: Seedance 2.5 (ברירת מחדל) ו-Wan 3.0, כל אחד ב-720p או 1080p. קרדיטים לקליפ של 5 שניות: Seedance 720p = 5, Seedance 1080p = 12, Wan 720p = 1, Wan 1080p = 2 (קרדיט ≈ $0.47–0.50 עלות AI). קרדיטי מסלול מתאפסים בכל חידוש; קרדיטים מחבילות לא פגים. קליפ שנכשל מחזיר את הקרדיטים אוטומטית.

## סיור אינטראקטיבי

מכל פרויקט אפשר לבנות גם סיור שהקונה מסתובב בו בעצמו (שלב "סרטון" ← "גם סיור אינטראקטיבי"):

1. **כניסה מהחזית.** מסמנים את הדירה על תמונת החזית. הקונה לוחץ עליה, ומעוף מצלמה של 5 שניות מתקרב אליה. הפריים האחרון הוא חיתוך של אותה תמונה סביב הסימון, כך שהמצלמה מתקרבת בדיוק לדירה שסומנה.
2. **מבט 360° בכל חלל.** מכל תמונה נוצרת פנורמה ביחס 2:1 (Seedream 5.5), שמוצגת בצופה WebGL: גוררים כדי להסתכל מסביב, צביטה או גלגלת לזום, חיצים במקלדת.
3. **תוויות בין החללים.** כל חלל מוביל לבא אחריו ולקודם לו לפי סדר התמונות בפרויקט. בסטודיו גוררים כל תווית אל הפתח המתאים וקובעים את המבט הראשון בכל חלל.
4. **תצוגת תאורה.** בוקר, יום, שקיעה ולילה. כל תאורה היא אותה פנורמה באור אחר, והמבט לא זז כשמחליפים.
5. **קישור לשיתוף.** `/tour/<מזהה הפרויקט>`, פעיל רק כשבעל הפרויקט מדליק "קישור ציבורי". העמוד נקרא בשרת ומחלק כתובות חתומות ליום אחד, רק לקבצי הסיור של אותו פרויקט.

הפנורמות נוצרות ב-AI מתוך תמונה אחת, כך שמה שמחוץ לפריים הוא השלמה. לכן הסיור מסומן תמיד "הדמיה להמחשה בלבד".

עלות: קרדיט אחד לכל תמונת 360° (כל תאורה היא תמונה), קרדיט למבט הקרוב, ומעוף המצלמה במחיר קליפ רגיל באיכות שנבחרה. מה שכבר נוצר לא מחויב שוב כשמוסיפים חללים או תאורה. עלות ה-AI לתמונה היא כ-$0.05.

במצב בדיקה (`FAL_MOCK=1`) הפנורמות הן תמונת רשת מצוירת, כדי לבדוק את כל הזרימה בלי לשלם.

## מסד הנתונים

הטבלאות יושבות בפרויקט Supabase studio-hq עם קידומת `re_` (בלי לגעת בטבלאות הקיימות). הסכמה המלאה: `supabase/migrations/`. כל הכתיבה עוברת דרך השרת; משתמש רואה רק את השורות שלו.

## איפה לשנות דברים

- `lib/plans.ts` — מחירים, קרדיטים למסלול, חבילות וכמה קרדיטים עולה כל מודל.
- `lib/presets.ts` — חללים, תנועות מצלמה, אור, הפרומפט והמודלים.
- `lib/business.ts` — פרטי העסק לתנאי השימוש ולפרטיות. **למלא לפני השקה, ולתת לעורך דין לעבור על `/terms` ו-`/privacy`.**
- `lib/reel.ts` — העריכה: מעברים, טיפוגרפיה, "לפני ואחרי".
- `lib/tour.ts` — הסיור האינטראקטיבי: הפרומפטים, התאורות ומיקום ברירת המחדל של התוויות. המודל והגדלים ב-`lib/presets.ts` (`TOUR_IMAGES`), המחיר בקרדיטים ב-`lib/plans.ts` (`CREDITS_PER_TOUR_IMAGE`).
- `lib/pano.ts` — הצופה ב-360° (WebGL, בלי ספריות).
- `app/globals.css` — העיצוב.
